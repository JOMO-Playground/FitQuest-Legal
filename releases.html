This is the public release record for testers. FitQuest separates implemented behavior, verified behavior, and work that is still gated.

Internal testing

Version 2.1.0 · Android code 6

The first Play-qualified quest engine.

Progressive workout generation, recoverable sessions, evidence-backed levels, improved daily movement sourcing, account recovery, and the new Quest Cut identity are in the internal-test bundle.

CORE

Quest progression

Workouts move through readiness, warm-up, main work, cooldown, and debrief. Difficulty responds to completed evidence and recovery—not button taps.

MOVE

Honest movement data

Health Connect is preferred for all-day Android Steps. The foreground sensor remains available and visibly labelled as partial.

SAFE

Recovery routes

Password-reset links now reach a public bridge back into FitQuest. Remote account deletion and local device erasure remain separate actions.

NEXT

Cloud recovery gate

Automatic and manual restore logic is implemented. Production backup activation remains blocked until private-bucket owner isolation passes its two-user smoke test.
